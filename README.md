# Sistema de Gestão de Academia

## Status do projeto
Em desenvolvimento

## Tecnologias utilizadas
- Java
- MySQL

## Time de desenvolvedores
- Murillo

## Objetivo do software
O sistema tem como objetivo auxiliar a administração de uma academia, centralizando o cadastro e a consulta de alunos, planos de matrícula e treinos em uma única aplicação desktop.

## Funcionalidades do sistema
- Cadastro e listagem de alunos
- Cadastro e listagem de planos de matrícula, vinculados a um aluno
- Cadastro e listagem de treinos, vinculados a um aluno
- Navegação entre as telas a partir de um menu principal
